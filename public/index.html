Univerzalni AI agent koji radi, a ne samo odgovara

Jedan robot — chat, mejl, CRM, fakture, support, kod, podaci.

Multi-tenant izolacija, 6 orchestration patterna, MCP alati, tri sloja memorije, budžet i audit trag. Ugrađuje se kao JS widget u bilo koji sajt ili kao API u bilo koji interni proces.

Gateway na ovoj adresi 13 agenata 6 patterna MCP: stdio + HTTP Bez npm zavisnosti Cost tracking po tenantu
GET /v1/agents GET /v1/tools GET /metrics GET /readyz

Kako se ugrađuje (bilo koji sajt)

<script src="https://robot.vasa-domena.com/widget.js"
        data-tenant="demo-shop"
        data-agent="support"
        data-auto="1"
        data-color="#ff6a00"
        data-title="Podrška"
        defer></script>

Kako se poziva iz koda (bilo koji proces)

curl -X POST http://127.0.0.1:8787/v1/agents/support/run \
  -H "content-type: application/json" \
  -d '{"input":"Status narudžbine 1042?","tenantId":"demo-shop"}'

# streaming (SSE)
curl -N -X POST http://127.0.0.1:8787/v1/agents/support/stream \
  -H "content-type: application/json" \
  -d '{"input":"Napravi ponudu za prima d.o.o."}'

Šest orchestration patterna

router

Prepozna namjeru i proslijedi nadležnom agentu (bez LLM-a gdje može — jeftinije).

sequential

Linearni tok: analiza → plan → checklista → izvještaj.

orchestrator-worker

Planer razbija zadatak, worker agenti izvršavaju, orchestrator sintetiše.

fanout / fan-in

Isti ulaz pod 3 ugla (pravno, finansijski, operativno), pa spoj u jedan odgovor.

handoff (p2p)

Support predaje billing-u, billing tehničkom — bez ping-pong petlje.

magentic

Plan → akcija → refleksija → korekcija, dok kritičar ne kaže „dovoljno dobro".
